# Q_GEOMETRY_MINIMAL_REPORT

**Mission: MINIMAL Q-GEOMETRY CUT.** One question only:

> Does the set `Q` of secant directions generated by bad parameters ever contain a direction
> that is **not** in `L(f₁, 2e)`?

Scope respected: no Lean file was written or modified, no axiom was added, no `sorry`/`admit`,
no Johnson/list-size statement was used or reopened, no broad parameter sweep, and the frozen
items (support geometry, occupancy, κ-charging, list decoding) were not touched. The only new
artefact besides this report is the measurement script
`analysis/q_geometry_minimal_cut.py` with its transcript
`analysis/q_geometry_minimal_cut_output.txt`.

---

## 0. Answer

**No — never, and never possibly.**

**DECISION: CASE B.** Every secant direction produced by a base point and a bad parameter lies in
`L(f₁,2e)`, on every instance tested (**1247** instances, exact arithmetic, zero exceptions), and
this is not an empirical accident: it is the already-proved secant lemma (Lemma A / Corollary A′
of `MINIMAL_CHARGING_THEOREM.md`), so **CASE A is unreachable by any instance whatsoever**. The
search branch "Q leaves L" is closed a priori, not merely unobserved.

Restated as the one-line proof (all that is used: `C` a subspace, `wt` subadditive and invariant
under nonzero scalars):

```
(γ−γ₀)(f₁ − q) = (γ−γ₀)f₁ − (c−c₀)
               = (g(γ) − c) − (g(γ₀) − c₀)        with g(γ) = f₀ + γf₁ ,
so   wt(f₁ − q) = wt( (γ−γ₀)(f₁−q) ) ≤ wt(g(γ)−c) + wt(g(γ₀)−c₀) ≤ 2e ,   i.e.  q ∈ L.
```

Nothing in the argument distinguishes the base point `γ₀` from the other endpoint, so the same
one line gives the stronger statement `D(B) ⊆ L` for the **full** pairwise direction set — Phase
III of the wider programme is therefore already settled in the affirmative, with no experiment
needed. The experiment below is a consistency check of the recorded data against this, plus the
follow-up measurement CASE B asks for.

## 5. The CASE-B follow-up measurement: is `Q` proper inside `L`, or can it exhaust `L`?

The mission permits exactly this one further look, and no decision beyond it. Three quantifier
levels must be distinguished; they answer differently.

| version of `Q` | definition | exhausts `L` with `|L| ≥ 2`? |
| --- | --- | --- |
| `Q_canonical` | one base point `γ₀`, lex-least witness for every `γ` | **never** (0 / 1247) |
| `Q_base` | one base point `γ₀` and one witness `c₀`, all witnesses of the other `γ` | **never** (0 / 1247) |
| `Q_union` | union over all base points *and* all witness selections | **yes**, 22 instances, largest `|L| = 22` |

* `Q_canonical = L` and `Q_base = L` occur in 124 instances, but every one of them has `|L| = 1`
  (a single admissible direction), i.e. the equality is vacuous.
* The largest genuine exhaustion of `L` is by the *union* over base points:
  `RS[4,3]/F5`, `e = 1`, `f₀ = (0,0,0,0)`, `f₁ = (0,0,0,1)`, `#Bad = 5`, unfiltered witnesses,
  `|L| = |Q_union| = 22`.
* Typical size gap for a single base point: over the 930 instances with `|L| ≥ 5`, the mean of
  `|Q_union| / |L|` is `0.28`; the largest single-base direction set observed is `|Q_base| = 13`
  against `|L| = 131`.
* **Caveat that kills the naive substitution.** For a fixed base point `|Q| ≤ |B| − 1` by
  definition, so most of the observed properness `|Q| < |L|` is forced by cardinality alone and
  carries no geometric information. Consequently, feeding `|Q|` in place of `|L|` into
  `|B| ≤ κ_max + |L|(|L|−1)` is **circular**: it yields
  `|B| ≤ κ_max + (|B|−1)(|B|−2)`, which is vacuous. Any usable improvement must bound `|Q|` by a
  quantity independent of `|B|`.
* Only 13 instances have `|L| ≥ 2` together with `#Bad − 1 ≥ |L|`, the regime where properness is
  *not* forced by cardinality. In **all 13** the direction set collapses completely to
  `|Q| = 1` (`RS[4,2]/F5` and `RAND[6,3]/F5`, `e = 1`, `#Bad = 5`, `|L| ∈ {2,3,4}`): the whole bad
  set sits in a single pencil member. That is the opposite extreme from exhaustion, and it is the
  only regime in the present data where the question has content. No decision is drawn from 13
  instances; recorded as an observation, not a claim.
* Collision frequency (Phase-I raw datum, no interpretation): `q(γ₁) = q(γ₂)` occurs for the
  canonical selection in 293 / 1247 instances; the largest observed deficiency
  `(#Bad − 1) − |Q_canonical|` is 9.

## 7. Consequence for the next move

The cut did its job: it removes the "`Q ⊄ L`" branch permanently, and it removes with it the hope
that `D(B)` is a *strictly larger* object needing separate treatment — `D(B) ⊆ L` is free. So the
second-order geometry of the witness point set cannot be found by asking *where* the directions
live; it must come from *how many* they are and *which affine relations* they satisfy inside the
ball `L`.

The single best next question, minimal again and now genuinely undecided, is the one isolated in
§5's last two bullets:

> For a fixed base point, is there an unconditional bound on `|Q|` (equivalently, on the number of
> directions determined by the witness point set) that is **independent of `|B|`** — or, in the
> opposite direction, can a bad set with `|L| ≥ 2` and `#Bad − 1 ≥ |L|` ever have `|Q| ≥ 2`?

Both halves are decidable by small exact configurations, and the answer selects between
"direction-counting can still pay" (a Rédei-type input, `|B| ≤ 2|Q| − 3` unless `B` is one pencil
member) and "the direction level is exhausted, move to the incidence structure
`I = {(γ, q(γ))}`". No further work on `Q` is warranted before that question is answered.
